      AI Settings

      Configure a local (LM Studio / Ollama) or cloud (OpenAI, Claude, Mistral, etc.) model for AI-assisted creation of designs and presentations.

      Examples
      • LM Studio (local): Provider OpenAI-compatible, Base URL http://localhost:1234/v1, Model as shown in LM Studio, API key optional
      • Ollama (local): Provider Ollama, Base URL http://localhost:11434, Model e.g. llama3.1
      • OpenAI: Provider OpenAI-compatible, Base URL https://api.openai.com/v1, Model e.g. gpt-4o-mini, API key required
      • Anthropic (Claude): Provider Anthropic, Base URL https://api.anthropic.com/v1 (or blank), Model e.g. claude-3-5-sonnet-latest, API key required
      • Mistral: Provider OpenAI-compatible, Base URL https://api.mistral.ai/v1, Model e.g. mistral-large-latest, API key required
